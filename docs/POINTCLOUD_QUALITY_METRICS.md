# 点云质量评测方法学（算法无关）

适用范围：任何 LiDAR(-惯性)/视觉融合算法输出的带色点云地图，或纯 LiDAR 点云。
本文只讲**怎么测**与**哪些测法已被证伪**，不含具体算法结论。
建立过程：Super-LIVO vs FAST-LIVO2 在 Retail_Street 招牌区域（约 6.7 m × 1.1 m，A 52.3 万点 / B 45.3 万点）上的对照实验，55 个候选指标筛选 + 四项独立性与鲁棒性验证。

配套脚本（均在 `tools/`）：

| 脚本 | 用途 |
|---|---|
| `qc_metric_screen.py` | 一次算出 55 个候选指标在成对 patch 上的取值，存 npy |
| `qc_metric_report.py` | 区分度排序、尺度鲁棒、Spearman 冗余聚类 |
| `qc_validate_v1.py` | 条件相关性、密度下采样鲁棒、栅格深度分层 |
| `qc_bootstrap.py` | patch 级 bootstrap 置信区间 + 对半分割 |
| `patch_compare.py` | 单区域裁剪的正面对比（密度、法向分层、渲染图） |
| `pointcloud_ghost_eval.py` | 绝对网格孤立度、邻域外推残差 |
| `render_sharpness.py` | 沿轨迹虚拟相机的鬼影点占比 |

## 1. 推荐指标（V1.0）

四个一级维度，其中 Q4 目前只作诊断。所有指标都要**分 patch 报告**，不要只报全图一个数。

### Q1 局部空间离散度 — `G00_Nb_Radius@K10`

定义：每个点到其第 10 近邻的距离，取均值。单位 mm。

- 反映"点是否落在该落的地方"，即局部采样尺度与空间弥散。
- 趋势：越小越好。
- 必须用**固定邻居数**而不是固定半径：固定半径在稠密区会引爆内存，且不同密度区域不可比。
- 参考值：干净稠密地图 8–10 mm（@10cm 体素尺度）；弥散地图 11–12 mm。
- 已知混淆：与点数直接相关。若两组点数不同，先按下式扣除采样数量效应，再下结论：

```
理论基线  d_B/d_A = 1/sqrt(N_B/N_A)      （假设二维表面、均匀采样、同面积）
超额倍数  = 实测 d_B/d_A ÷ 理论基线
```

实测校准：官方云保留 87% 点时 G00 从 0.92→0.97 cm（+5.4%），理论预测 +7.2%，同量级。
注意这只是**理论基线**，Mid360 一类非重复扫描的入射角、遮挡、回波选择都会改变间距，不能当精确分解用。

### Q2 粗糙度空间不均匀性 — `G15_Roughness_CV@K25`

定义：每个点在其 25 近邻上做协方差分解，取 `sqrt(λ_min)` 为该点的局部粗糙度；然后求**所有点粗糙度的变异系数 std/mean**。

- 回答的不是"平均多粗糙"，而是"是否一部分区域很干净、另一部分很散乱"。
- 趋势：越小越好（质量在空间上均匀）。
- **已通过密度鲁棒验证**：把干净云随机下采样到 95/90/87/80/70%，每档 20 次，该指标只从 0.2950 单调**降**到 0.2757（std ≤ 0.0031）。也就是说它不会因为点变少而虚高，方向与密度混淆相反。
- 这是最有价值的单一指标，因为它与 Q1/Q3 都不同族。

### Q3 固定物理尺度的异常点比例 — `O02_ROR_Ratio@3cm`

定义：3 cm 半径内邻居数 < 6 的点占比。

- 趋势：越小越好。
- **与 Q1 独立**，已验证（见 §3 实验1）：组内 Spearman 只有 −0.22/+0.28，按 G00 分层后仍差 7–16 倍。
- 高效实现：一次 `tree.query(P, k=60)` 同时得到 Q1 与 Q3，别用 `query_ball_point`：

```python
dd, _ = cKDTree(P).query(P, k=60)
G00 = dd[:, 9].mean()
O02 = (dd < 0.03).sum(1) < 6      # 占比
```

- 阈值（3 cm / 6 个）要与场景尺度绑定；换传感器要重标。

### Q4 投影域颜色污染 — `Raster Salt-Pepper Ratio`（**当前仅诊断**）

定义：把点云正交投影到表面主平面栅格（像素 2 mm），沿面法线做 z-buffer，取每个像素最近点的亮度；空洞用最近邻填充；统计 `|L − median_filter(L, 5)| > 40` 的像素占比。

- 趋势：越小越好。
- **必须在栅格域测，点域颜色指标全部无效**（见 §4）。
- 当前状态：整图差异可以很大（实测 7.65% vs 14.43%），但逐 patch 的方向一致性差（只有 4/10 patch 同向，bootstrap 95% CI 跨 0）。**说明它由少数高对比区域主导，还不能进综合评分**，需要跨扫描数据才能定级。
- 用它之前必须先做深度分层拆解（§3 实验3），否则分不清"真实颜色污染"和"两层表面投影碰撞"。

### 备用诊断（不进综合评分）

- `D05_NN_P95`：第 95 百分位最近邻距离。与 Q1 同族但看最差区域，用来定位"哪块最散"。区分度最高（d_z 4.69）但与 Q1 重复计权，故只作诊断。
- `O08_Isolated_Ratio@1cm`：1 cm 格内只有 1 个点的点占比。语义最直白（浮点比例），相对差最大（+44%），但与 Q1 族 |ρ|>0.95。

## 2. 实验设计要点（比指标本身更重要）

1. **相同 ROI**。不同区域的密度/纹理差异会淹没质量差异。做法：从两个系统的地图里按同一物理边界裁剪，或先拟合共同坐标系。
2. **成对 patch，不要只比两个总数**。把 ROI 沿面内轴切成网格（经验值：8×2 或 16×16，每格 ≥3000 点），同位置配对。这样每个指标能得到 N 个成对样本，才能算效应量和置信区间。
3. **区分度用成对 d_z，不用相对差**：

```
d_z = mean(B_i − A_i) / std(B_i − A_i)
```

   相对差 85% 的指标可能 d_z 只有 1.3（patch 间方差太大），相对差 20% 的指标可能 d_z 4.7。
   再配三个量：bootstrap 95% CI、P(d_z>0)、**逐 patch 方向一致率**。一致率低于 80% 的指标不要采信。
4. **参数鲁棒**：同一指标在多个邻域尺度（K=10/25/60）或阈值下重算，符号必须一致。实测 `D08_Density_CV` 在 1 cm 与 2 cm 网格上符号相反，直接弃用。
5. **冗余聚类**：算所有指标间的 Spearman，|ρ|>0.95 归一族，每族只留 d_z 最大的代表。否则"四个维度"其实是同一个维度算四遍。
6. **警惕组间（ecological）相关**：两组合并算出的相关性可能纯粹来自两组整体偏移。必须**分别在 A 内、B 内**再算一次。实测 `Spearman(G00,O02)` 合并 0.661，组内 −0.217 / +0.275 —— 合并值是假象。
7. **密度必须单独控制**：任何"先找邻居再算"的量都被点密度混淆。用随机下采样实验（§3 实验2）证明指标不是密度假象，才允许进体系。
8. **点数少的区域要显式排除并报告**：实测招牌左侧 0–2 列 patch 不足 3000 点被剔除，这本身就限制了结论的空间覆盖范围，必须写进结论。

## 3. 四项验证实验的可复用模板

### 实验1 两指标是否真正独立

对每个 cell 同时算 X 和 Y，然后：

- 合并 / 仅A / 仅B 三个 Spearman；
- 按 X 的分位数分层（三分位），比较同层内 Y 的 A/B 差异倍数；
- 在 A 上拟合 `log(Y) ~ log(X)`，报告 R² 与 B 的超额倍数 `exp(mean(log Y_B − pred))`。

判定：组内 Spearman 弱 + 分层后仍显著分家 + R²≈0 ⇒ 独立维度。

### 实验2 密度鲁棒性

把"较好的那组"随机下采样到 100/95/90/87/80/70%，每档 ≥20 次重复，重算指标。

判定：指标随密度下降而**不升高**（最好如 Q2/Q3 那样略降或持平），且较差组仍高于所有档位 ⇒ 不是密度假象。

### 实验3 栅格域质量到底来自哪一层

投影栅格后按 `dn − zbuffer[pixel]`（点到可见皮的深度差）分层，各层单独重新栅格化并计算指标：

| 层 | 含义 |
|---|---|
| 0–1 cm | 可见皮 |
| 1–4 / 4–8 / >8 cm | 皮后各层 |
| <0 | 皮前（浮点） |

另加一组"只保留局部平面残差 <1.5 cm 的点"。

判定：若"皮层单独算" == "全点算"，说明指标完全由可见皮贡献，后层无关；若剔除离面点后指标不变，说明是表面自身的问题（颜色或贴合误差），不是多层投影碰撞。

### 实验4 稳健性/复现

- 首选：每种模式 5–10 组**独立扫描**，做配对检验 + bootstrap CI。
- 只有一份数据时的替代：patch 级 bootstrap（2000 次重采样 patch 索引）+ 对半分割（奇/偶列分别算 d_z）。
- **必须声明局限**：这只能证明"差异在本 ROI 内空间稳健"，不能证明"换个场景还成立"。

## 4. 已被证伪的指标（别再算）

在招牌 ROI 上 d_z≈0、方向一致率≈50%（即与随机无异）：

| 指标 | d_z | 失效原因 |
|---|---|---|
| `G03_Plane_MAD` / `G05_Plane_P95` | 0.09 / 0.88 | patch 内同时含前景面板与后墙两张皮，中位数被皮间空隙主导（MAD≈空隙的一半），对鬼影完全不敏感。**"相对全局主平面的偏离"在有前后景的场景里没有意义。** |
| `O10_Off_Plane_Ratio` | 0.07 | 同上 |
| `G12_Normal_Dispersion` | 0.03–0.07 | 两张皮各自法向都很一致，层间差异不体现在法向角上 |
| `G08_Surface_Variation` | −0.16~−0.27 | 归一化后与 Q1/Q2 反向，且无区分度 |
| `D04_NN_CV` | −0.19 | 与 Q2 不同，最近邻距离的 CV 不敏感 |
| `D01/D02/D05` 之外的密度族 | — | `D08_Density_CV` 尺度符号翻转；`D09_P5`、`D11_Empty_Cell_Ratio`、`D12_Occupancy_Entropy` 恒为常数 |
| **全部点域颜色指标** | C03 −0.02、C04 0.39、C15 0.18、C16 0.14 | 点域里每张皮各自颜色都稳定，只有投影叠到同一像素才混色 ⇒ **颜色质量是投影表达质量，只能在栅格域测** |
| `E04_Edge_Gradient` / `E11_Projected_Sharpness` | 0.46 / 0.59 | 稀疏栅格下被空洞填充主导 |
| `E07_Edge_Completeness` | 0.22 | 同上 |

另外：`O01_SOR_Ratio`（d_z 0.93）与 Q3 高度重叠，且对阈值更敏感，不单独保留。

## 5. 实现坑（都踩过）

1. **`cKDTree.query()` 返回 `(距离, 索引)`**。写成 `_, dd = tree.query(P, k=2)` 会把**索引当距离**用，NN 距离族与依赖它的色差指标全部失真（实测输出 15580 这种"米"级荒谬值）。
2. **固定半径邻域 `query_ball_point` 在稠密点云上是内存炸弹**。改成一次 `query(k=K)` 再用 `(dd < r).sum(1)` 得到半径内计数，既省内存又能顺带算 Q1。
3. **随机抽样会吸收鬼影**。从千万级点里抽 25 万做局部平面拟合，NN 距离被放大 ~4 倍，参考平面本身跨 10 cm 以上，正好把 5–15 cm 的鬼影吸收进平面。测鬼影/弥散**不能抽样**。
4. **自拟合局部平面看不见鬼影**。鬼影层自己也是一张平面，拟合时会把平面拉向自己。要么用"邻域外推"（排除自身质心），要么用 z-buffer 沿射线定义表面（密度无关，推荐）。
5. **中位数被大平面主导**。全图中位数指标看不见肉眼在意的细高对比结构（笔画、边界）。要么分 patch，要么按对比度把 cell 分成 edge/flat 两组分别报。
6. **PCD 头要按 `SIZE × COUNT` 累加算点步长**。CloudCompare 导出常见 `FIELDS rgb x y z _` + `SIZE 4 4 4 4 1` + `COUNT 1 1 1 1 4`，只按 SIZE 求和会字段错位，坐标跑到几万米。
7. **`FIELDS` 顺序不固定**，按名字查偏移，别假设 `x y z rgb`。
8. **PCL 把 RGB 塞进 float32 的位模式**，必须 `view(np.uint32)` 按位重解释；`astype(np.uint32)` 是数值转换，结果是错的。
9. **渲染栅格不做空洞填充会让椒盐指标被背景主导**。用 `distance_transform_edt(..., return_indices=True)` 最近邻填充后再算。
10. **两套地图的世界系可能不同**（重力对齐轴、原点、yaw）。做虚拟相机渲染时**各用各自的轨迹**当相机，比指标就不需要对齐；若必须对齐，用几何搜索时间/位姿偏移，别假设时间戳同域。

## 6. 一句话流程

裁同一 ROI → 拟合共同主平面 → 切 patch → 每 patch 算 Q1/Q2/Q3(+D05) → 成对 d_z + 一致率 + bootstrap CI → 组内 Spearman 查冗余 → 密度下采样查混淆 → 栅格域单独测颜色（必须先做深度分层） → 有独立扫描才把 Q4 升级为一级指标。
