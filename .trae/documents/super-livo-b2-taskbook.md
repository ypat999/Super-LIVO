## §3 实验规格

### E0（M0，最高优先级）10 Hz 可行性判定

**前提纠错（重要）**：P0-F / P0-C 用的**本来就是 10 Hz 图像**（`19e` 用 `read_lidar_stamps(stride=1)` + 配对 `(k,k+1)`；P0-A 实测「图像戳 = LiDAR 头戳、1:1，std=0」）。§36.2 里「相机 1 Hz」是误记。⇒ **不存在"从 1 Hz 迁移到 10 Hz"这一步，P0-F 的 0.1387°→0.051° 已经是 0.1 s 区间的成绩。**

**为什么仍要做 E0**：初看存在一个致命疑问——若 LIO 的区间误差是白噪声型（∝√Δt），0.1 s 处只剩 0.047°，与图像链 0.0489° 相等 ⇒ 余量归零。**实测否掉了这个担忧**。

**E0 实测结果**（`/tmp/e0_dt_scaling.py`，日志 `/tmp/e0_dt_scaling.log`，未改动仓库）

| Δt (s) | 0.1 | 0.2 | 0.3 | 0.5 | 1.0 |
|---|---|---|---|---|---|
| LIO 区间误差 med (n=200) | **0.1619°** | 0.1501° | 0.1796° | 0.2102° | 0.2484° |
| P90 | 0.2841° | 0.2547° | 0.3185° | 0.3435° | 0.4558° |
| √Δt 白噪声预言（锚 0.1 s） | 0.1619° | 0.2294° | 0.2804° | 0.3619° | 0.5119° |
| 实测/预言 | 1.00 | 0.65 | 0.64 | 0.58 | 0.49 |

- 标度极弱：**e ∝ Δt^0.211**（白噪声应 0.5，偏置应 1.0）；e(1 s)/e(0.1 s) 仅 **1.53×**。
- 分解 e² = c² + w²Δt ⇒ **c = 0.1381°（与 Δt 无关的逐帧抖振）+ w = 0.2088°·s^−½**，拟合残差 rms 0.0092°（5%）。相关项占方差：**0.1 s 81% / 0.5 s 47% / 1.0 s 30%**。
- **自洽校验**：c = 0.1381° 与 P0-F 的基线 0.1387° 逐位吻合 ⇒ 修正器消除的正是这个 Δt 无关的逐帧抖振项，机制清楚。
- 稳健性：换段 k=100/500/900 趋势一致；τ=0（直接取发布戳）0.1225~0.2402 形状不变。

**结论**：LIO(0.1 s) = **0.1493~0.1619°**，比图像链 0.0489° **大 3.0~3.3 倍** ⇒ **余量充足，M0 门通过，M2 可开**。

**输入**：`/home/ywj/slam_data/retail_abl/base.txt`（10 Hz TUM）+ `/livox/imu`（203 Hz）。
**脚本**：`/tmp/e0_dt_scaling.py`（临时目录，不入库），复用 `_p0_rot.py` / `_p0_visual.py`。
**指标**：

1. LIO 区间旋转误差 vs IMU 的 med / P90，在 Δt = 0.1 / 0.2 / 0.3 / 0.5 / 1.0 s 五点；
2. 与 √Δt 白噪声预言值 `0.1493·√(Δt/1.0)` 的比值；
3. 图像链 1 s 区间误差序列的 lag-1..5 自相关（判断误差是慢变还是逐区间独立）。

**通过门**：`LIO(0.1 s) ≥ 2 × 0.0489°`（即 ≥0.098°）⇒ 实测 0.1493~0.1619°，**通过（3.0~3.3×）**。
**已闭合的负向假设**：`LIO(0.1 s) ≤ 0.06°` 不成立，故不触发"M2~M5 冻结"。

**E0 附带产出（比门本身更重要，直接改 Phase 1 的噪声模型）**
1. **视觉误差短记忆相关**：0.1 s 区间误差 lag-1 自相关 **+0.461**，lag-3 已 ≈0（+0.043）；1 s 链误差非重叠 lag-1 +0.445。⇒ 因子图把区间残差当 i.i.d. 会**过自信**。
2. **定量校准（2026-11-16 R10 探针实测，初稿"1.65×≈1.52× 吻合"已被推翻）**：初稿把"σ_eff 0.0322° vs 实测 0.0489° = 1.52×"当作 W3 过自信的证据，但该比较口径不对等（主轴均值 σ 对向量模 rms）。探针实测：**边际/口径比仅 1.08×**（W3 等效 σ 0.0360° vs |g| 边际 rms/√3 = 0.0389°）；AR(1) **逐轴强各向异性** ρ=[0.024, 0.802, 0.488]（非各向同性 0.46）；**λ0 灵敏度极平**：σ×1.52 而 λ0 不动 ⇒ 结果移动 ≤0.001°，且尺度不变性成立（σ×s 且 λ0×s ⇒ 同解）⇒ **R10 不阻塞 M2、不需重搜 λ0**。ρ≈0.80 的轴本质是慢变偏置，归 E4 相关误差治理。数字全账见总账 §36.12，处置见 §7 R10。
3. **LIO 发布戳的位姿对帧内插值极不友好**：τ=0.055 s（半帧）处 LIO 区间误差 0.343°，比 τ=0 的 0.14° 差 2.4×。⇒ M5 的 `T_corrected(t)` 查询**必须优先用精确戳、次选 SO(3) slerp，禁止姿态分量线性 lerp**。

#### E1 静态审计结论（2026-11-16 完成，代码行号已核实）

**状态链事实**：30 维状态（vel=6-8，`state_layout.hpp:37-44`）；propagate 名义传播 `s.v += (a_w + s.g)·dt`（`unified_estimator.cpp:50`），Φ 含 vel←rot/vel←ba/vel←grav 交叉项（`:72-76`）；**Pvv 唯一增大项** `q(kVel)=acc_noise²·dt=1e-4·dt`（`:83`，yaml `acc_noise 0.01`）⇒ 每秒 +1e-4 (m/s)²。
**先验注入**：`buildLidarPrior` 纯信息形式，Hv=1/σ_v²=16I、b_v=16·(v−v_lio)（`visual_b_node.cpp:1343-1351`），σ_v=0.25（yaml L81）；**独立对角块，不显式用 Pvp**（耦合只经 30×30 求逆隐式发生）。`lioVelocity` 对 pose_cache_（=同一 /lio/odom）取 t−0.1s 端点差分，dt∉[0.05,0.30] 或 |v|≥10 ⇒ **该帧速度块整体静默缺席**（`:1354-1377`）。`lidarUpdate` 只在 `processVisualFrame` 内被调（`:863`），**onOdom 不做任何更新**；k=min(10,max(1,accum/0.1))（UE:108），σ 不按 √dt 归一。
**失配机制（全部坐实）**：
- `clampSpeed`（UE:285-296）只缩 `state.v`，**不动 P、不动 ba/g** ⇒ 每帧误差源继续泵速，与 393 次重复触发一致。
- `pose_only`（UE:344-349）把视觉 dx 的 vel/bg/ba/grav 分量**置零但协方差照常写回**（`:378`）⇒ 状态/协方差系统性失配；且 info-cap 用被压小的 P⁻¹ 定 cap（`:188-201`），自指反馈。
- 分块限幅（UE:359-375）任一块超限则 dx **整体**等比缩小 ⇒ rot/pos 创新大时速度修正被连带缩掉。
- `resetState`（UE:306-307）grav/外参 ×1e-8 ⇒ 重力被永久冻结在初值，其方向/幅值误差 θ_g 经 `a_w+s.g` 变成**常值泄漏**：θ_g=0.3° ⇒ 0.051 m/s²，与 6.21 m/s ÷ 135 s ≈ 0.046 m/s² 的末段斜率同量级。
- 数值条件数 ~1e8 + 每帧两次 30×30 求逆（UE:328-330、188）。

**「为什么滤波器拒绝改变速度」的定量判据（E1 用数字裁决，勿再推断）**：
若速度先验以 r 次/秒生效（每次增益 w=16k），稳态 Pvv* ≈ √(1e-4·r⁻¹·…) ⇒ 速度修正带宽 ≈ √(1e-4 × 16r)。r=10（10 Hz，k=1）⇒ 带宽 0.126 s⁻¹、稳态误差 = 泄漏/0.126 ≈ **0.4 m/s**——**远小于实测 6.21**。⇒ 单靠 H1（增益塌陷）解释不通，必属下列之一：① `has_v` 真值比例极低（先验实际很少生效）；② k/σ 实际口径与假设不符；③ 泄漏远大于 0.05（转向段 R 误差 × a_w）；④ clamp–reset 循环吞掉修正。**这四个就是 E1-B 的裁决点**，插桩必须逐帧记录 `has_v` 失败原因计数、实际 `lidar_dt_accum_`、每次更新的 `Pvv_pre/w·k/dx_v/创新`。

### E2（M3）生产节点保真 + 场景覆盖（不是"1 Hz → 10 Hz 迁移"）

**前提已纠**：P0-F 的 0.1387°→0.051° **本来就是 0.1 s 区间（≈10 Hz）的成绩**（见 E0）。所以 E2 不再验证"10 Hz 能否工作"，而是验证**离线 Python 结论能否在 C++ 生产节点上复现**，以及**场景/成像条件的覆盖**。

**这不是"确认"，是"证伪"**。要否掉的是"离线脚本赢在理想化条件"这一解释。

| 组 | 输入 |
|---|---|
| E2-A | Super-LIO 原始姿态 |
| E2-B | P0-F 纯旋转滑窗 |
| E2-C | B 当前视觉估计器 |
| E2-D | P0-F 旋转滑窗 + B 原有平移约束（**仅观察组**） |

**E2-D 的防重复计数规则**（三选一，必须写清用了哪个）：① 不相交特征集（按 track id 奇偶或时间片划分）；② 因子替换——MSCKF 消元时**冻结旋转 Jacobian 块**，只让其约束平移可观测方向；③ 逐块重算信息矩阵并显式扣除旋转分量。
**重点**（全部是"离线脚本无法代表生产"的部分）：真实 10 Hz 全局快门（海康）连续回放下的**时间同步与线程调度**；室内 / 走廊 / 楼梯**场景覆盖**；运动模糊下协方差是否仍可信；视觉丢帧时能否**自然退化**（渐进回退 LIO 而非跳变）；输出是否改变真实转向。

**通过门**：0.1 s 区间旋转误差 ≤ 0.5 × LIO 同区间误差；真实转向保留 ≥80%。

**E2-A 实测（2026-11-16，`Retail_Street` 全段 134.4 s / 1313 帧，详见 §36.14）**：

|---|---|---|---|
| 区间旋转误差 | ≤ 0.5 × LIO | 0.1330° → **0.0540°**（比 0.406） | **通过** |
| 真实转向保留 | ≥ 80% | **99.4%**（逐轴相关 0.991/0.991/0.999） | **通过** |

- 视觉因子 vs IMU：0.0572°（P0-F 离线同段 0.0477°，差 1.20×）；对应点位移与同起点 LK 差 0.02~0.05 px。
- **前置修复（阻塞项）**：生产 `PatchTracker` 的单层 5×5 SSD 模板匹配在本数据集不可用（位移饱和在 4√2 px、`r_vis` 偏差 1.3~9.0°）。已改为金字塔 LK（`search_radius` 语义变为 LK 窗口半边长，默认 4 ⇒ 9×9），其余接口与打分门限不变。

### E3（M3）地图层裂指标重建

**不再围绕 `k=16` 法向厚度扫参**（§36.8：其本底 6.79 mm 中 5.05 mm 与位姿无关，修到 ε=0 也只有 5.21 mm）。

**条件**：固定同一 LIO 轨迹、同一输入点云、同一地图表示；三臂 = LIO / 原始图像旋转 / 修正图像旋转；另注入 0.05° / 0.1° / 0.2° 已知扰动。
**指标**：① `_probe_layering.global_planes` 的**平面芯区多峰间距 `sep_cm`**（主判据）；② **去曲率 `hf_θ`**（副判据，需先给出 L0 基线标定）；③ 法向厚度（**仅守门**，要求不劣于同数据 LIO 基线）。
**必须包含前视墙面**：旋转位移 `δ×r` 垂直视线，对正前方墙面法向投影 ≈0%，只测侧墙会得出错误结论。
**`sep_cm` 的可复现性前提**（先定义再实验，否则数字不可比）：平面芯区的最小点数、内点率阈值、峰检测的最小间距与最小显著度，全部写进脚本常量并固定在报告里。
**`clip_rot` 定值**：0.06° / 0.15° / 0.30° 三档在**真实 10 Hz 数据**上对照后定。P0-E 的 0.06° 是近端线性模型反解（额外分层 ≤1 mm），P0-F 的 0.30° 是恢复力实验通过值，**两者验收依据不同，不可互相顶替**。
**通过门**：`sep_cm` 随注入幅度单调；前视/侧视墙面均可检出；`hf_θ` 与 `sep_cm` 趋势一致；修正臂不劣于 LIO 臂。

### E4（M4）视觉相关误差来源拆解

P0-D：随机分量按 1/√N 收敛，但**总残差 0.045° 中约 99% 与 N 无关** ⇒ 加特征数不是高收益方向。

| 组 | 特征处理 |
|---|---|
| A | 现有全部有效特征 |
| B | 剔除深度边缘与遮挡边缘 |
| C | 剔除局部平面不一致的离面点 |
| D | 增加动态目标剔除 |
| E | 4×4 网格分块独立估计 + 一致性筛选 |
| F | B + C + E |

**指标口径**：去看均值后的旋转残差、各网格估计之间的差异，**不要只看特征数或跟踪率**。
**必须防混淆**：4×4 网格单格内点数少 ⇒ 单格 σ 大 ⇒ "不一致"可能是**噪声**而非**系统偏差**。要求同时报告每格 N 与每格 σ̂，并只在 `N ≥ 30` 的格子上做一致性判决。
**通过门**：相同特征数量下相关误差下降；协方差与实际残差一致；分格不一致显著改善（P0-D 基线：2×2 单格解 vs 全图解 P50 **0.0438°**、P90 0.0950°、最差 2.846°）。
