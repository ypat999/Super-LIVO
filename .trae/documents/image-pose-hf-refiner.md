# 图像位姿高频抖动修正器（pose_refiner）实施方案 v2

> v2 依据外部评审全面修订。核心变更：**第一阶段改为「旋转优先」，平移暂不修正**；

## Context（为什么做这件事）

Super-LIO 每帧发布的是**每帧独立的 4 轮迭代 ESKF 后验**：H 与残差在当前迭代点重算，帧间没有任何一致性约束。这在 LIO 内部无害（LiDAR 匹配工作在分米尺度），但一旦把每帧位姿当成彩色地图的世界变换，帧间的微量抖动就会把同一面墙在不同帧投到不同位置 —— 表现为**分层/重影**而不是发糊。

消融已给出强相关证据：只改 Δ_anchor 上限，地图局部平面厚度严格单调恶化
`b_lio 7.11 mm ≡ d0 7.14 ≪ d1 12.30 ≪ fix34 14.66 ≪ d3 20.55 mm`（>10 cm 占比 0.4/0.4/0.8/1.8/12.8 %）。

**结论措辞（v2 收敛）**：当前消融实验表明，**帧间位姿注入不连续是已测试配置下彩色地图分层的主要影响因素**。图像观测质量、相机时间同步、投影位姿一致性仍需独立验证，不得提前定性。同时 `b_own` 的世界变换与相机投影位姿**双源不一致**（`visual_b_node.cpp` L1234 走 LIO，L1425-1451 走 own）是应当独立消除的工程缺陷。

同时 solution_b 统一估计器被判不可用：速度状态无观测 ⇒ run-to-run 发散（|v| 钉限幅 6.0，b_lio 臂 max 122.6，Δ_raw 中位 12–14 m）。

### 判决性实测数据

`/home/ywj/slam_data/retail_abl/`，同一 Retail_Street bag，均为**原生 ~10 Hz**（dt 中位 100.0 ms），
故 `tools/rtk_jitter.py` 里"官方 1 Hz 导出不可并列"的限制**对本组不适用**，可直接横比。
口径 = 3-tap 二阶差分 `hf[k] = p[k] − (p[k−1]+p[k+1])/2`，跨 >0.3 s 空隙的 k 作废。

| 轨迹 | hf_p P50/P90/max (mm) | hf_θ P50/P90 (mdeg) |
|---|---|---|
| base.txt（Super-LIO） | 3.85 / 6.71 / 43.3 | 510 / 998 |
| a_livo.txt（官方 FAST-LIVO2 LIVO） | 3.80 / 6.71 / 37.2 | 514 / 981 |
| fl2_lio.txt（官方纯 LIO） | 4.39 / 13.5 / 467 | 438 / 892 |
| dense.txt | 3.87 / 8.60 / 153 | 522 / 987 |

三条推论：
1. **官方 FAST-LIVO2 抖动与 Super-LIO 同级**（P50 差 1.3 %、P90 差 0 %）⇒ "超过官方"是明确数字门槛。
2. **旋转是主收益通道**：0.51° 在 5 m ⇒ 44.5 mm 切向展宽，比 3.85 mm 平移抖动大一个量级。
3. base 的抖动是**宽带**的：真实运动速度谱 86.7 % 能量在 0–0.5 Hz，但 hf 残差 91 % 在 >0.5 Hz（0.5–2.5 Hz 42.4 %、>2.5 Hz 48.7 %）⇒ **knot ≥0.3 s 的样条（截止 <1.7 Hz）表达不了主体，只能当低频正则层**。（注：3-tap 本身是高通滤波器，>2.5 Hz 占比含滤波 shaping，不能直接读作物理谱峰。）

### 已确认的用户约束

实时 ≤100 ms/帧 ⇒ v2 收紧为 **P95 ≤60–70 ms**；允许引入 Ceres（WSL 实测 `libceres-dev 2.0.0` 已装，g2o 未装，Sophus 由 `ros-humble-sophus` 提供）；验收四项全用；**新建独立包**，solution_b 估计器保留但默认不用。

## Proposed Design v2

### 核心思想

**不重新估计位姿，而是在 LIO 位姿上叠加一个小幅、时间受控、被多层安全网约束的修正场。**

```
第一阶段（旋转优先）：  R'_k = Exp(dθ_k) · R_k ,   p'_k = p_k(LIO) 不动
后续阶段（需证明）：    T'_k = Exp([dp_k; dθ_k]) · T_k
```

修正量之所以能比 LIO 抖得少，**理由不是模型平滑，而是测量源不同**：LIO 的抖动来自每帧重线性化的估计器过程噪声；图像相邻帧旋转由亚像素对应决定，理论上不受该噪声污染。但"图像真的更稳"是**待验证假设**，不是事实 —— 这正是 P0-C/P0-D/P0-F 要回答的问题。时间正则（λ2）**约束的是修正量 δθ 自身的高频变化，不是要求轨迹变平滑**，因此不会因为压抖动而压制真实运动。

### 第一阶段因子图（Ceres，纯旋转，窗口 15 帧 ⇒ 仅 45 维变量）

```
J = Σ_k ρ( r_vis,kᵀ Σ_vis,k⁻¹ r_vis,k ) + λ0 Σ_k ‖dθ_k‖² + λ2 Σ_k ‖dθ_k − 2dθ_{k−1} + dθ_{k−2}‖²
```

**视觉残差必须用完整 SE(3)/SO(3) 形式定义，不能对两个修正向量做减法**（因为修正是世界系左乘）：

```
r_vis,k = Log( R_vis,kᵀ · ( R'ᵀ_{c,k} · R'_{c,k+1} ) ),   R'_{c,k} = R_lc · R'_k · R_cl
```

- `R_vis,k` 来自相邻帧 **LK + RANSAC（双向跟踪）+ 5-point**；纯旋转/低基线场景走 **Homography** 分解路线。
- `Σ_vis,k` **动态**，由内点数、特征空间覆盖率、视差分布共同决定，不用固定常数。
- 平移尺度：第一阶段**不使用**视觉平移观测。原因（v1 的逻辑漏洞）：Essential Matrix 只能恢复旋转 + 平移方向，若模长回落到 LIO，则视觉对平移模长**没有任何独立观测能力**；而"LIO 深度 + PnP"能给出有尺度约束，但深度误差与被修正的 LIO 误差相关，会把相关误差当独立信息重复计权。

**先验合并（v1 缺陷：Λ0 与 Λa 语义重复）**：统一写成带协方差的单一项
`r_prior,k = Σ_δ^{-1/2} dθ_k`，不再分设两个拉回 LIO 的二次型；时间连续性由独立的 λ2 项控制。

### 分层安全网（v2 重写 —— 绝对钳位只限制幅度，**不保证帧间连续**）

v1 的反例：dθ_1 = +0.35°、dθ_2 = −0.35° 各自满足钳位，但修正量之间已跳变 0.7°。故六层缺一不可：

| 层 | 规则 | 防的是什么 |
|---|---|---|
| S1 绝对修正量 | `‖dθ‖ ≤ clip_rot`（后续阶段 `‖dp‖ ≤ clip_pos = 0.03 m`）球面钳位 | 离开 LIO 可信域（solution_b 发散的教训） |
| S2 **旋转 slew** | `‖dθ_k − dθ_{k−1}‖ ≤ slew_rot`，限制对象 = **修正量的一阶差分**（不是修正后角速度，也不是角加速度；三者需在代码注释中显式区分） | 修正量本身造成帧间跳变 |
| S3 **平移 slew**（后续阶段） | `‖dp_k − dp_{k−1}‖ ≤ slew_pos` | +3 cm↔−3 cm 造成 6 cm 位置突变 |
| S4 修正后运动学一致性 | 发布前用修正后轨迹重算 `twist`（有限差分），保证 pose/twist 同源；并检查修正后角速度不超过物理上限 | 非物理轨迹；下游读到与 pose 矛盾的速度 |
| S5 渐进淡出 | 门控退出时按 τ 帧线性衰减 dθ→0，**不瞬间回到 LIO** | 视觉失效瞬间制造一个新的阶跃（=分层源） |
| S6 求解失败处理 | Ceres 迭代失败/非收敛 ⇒ 沿用**最近可信解**再预测一帧，连续 M 次失败才转 S5 | 单次异常解污染地图 |

### 门控（v2：旋转与平移可观测性**分离**）

v1 缺陷：`baseline < 0.1 m` 就丢因子 —— 而原地/缓慢转向恰恰平移基线极小、**却正是最需修旋转的时刻**。

- 旋转门控：内点率 ≥0.5、**特征空间覆盖率 ≥0.4**（把图像分 4×4 网格，统计有内点的格子占比）、两帧公共视场 ≥30 %、Homography/5-point 退化判据（条件数）。
- 平移门控（后续阶段才启用）：视差中位数、深度可信度、尺度可观测性各自独立评估。
- 连续 N=10 帧无有效旋转因子 ⇒ 走 S5 渐进淡出回落 `lio`（等价当前最好的 b_lio 基线）。WARN 限速打印，参照 `super_lio.cpp:1426-1511` 的 `checkPoseTrust` 写法。

### 时间戳模型（v2 取消固定 −50 ms）

v1 的 `scan_half_period = 0.05` 硬编码只在"图像曝光中点恰好对齐扫描中点"的特例成立，否则人为引入 50 ms 偏差 ⇒ 20°/s 转向时 1°，**远大于 0.2° 目标**。改为显式模型：

```
t_img,mid = t_img,stamp + Δt_camera            # Δt_camera 由 P0-A 实测，不拍脑袋
T_LIO(t_img,mid) = slerp/lerp( LIO 位姿连续轨迹 ) # 用 pose_interpolation 的机制插值，不做平移补偿
```

LiDAR 扫描起始/结束/相机曝光中点是三个不同概念，必须分开。`img_time_offset` 属时钟域补偿（`LIVMapper.cpp:1056` 用法），不能与物理曝光延迟混成一个参数。

### 明确不做
- **样条主模型**：被实测频段判负；且 basalt 的 `se3_spline.h` 在本 checkout 缺失、未进 colcon 构建 ⇒ 不引入。
- **直接法 patch 作主通道**：官方 FAST-LIVO2 已实测其图像通道没压住 HF（a_livo ≈ base），因其同为逐帧独立优化、同样重线性化。
- **回环**：与压 HF 正交，引入全局不连续 ⇒ 仅在 P4 之后、且 RTK 数据证明存在**低频**系统性漂移时另案评估。
- **改动 solution_b 现有估计器**：保留，默认不用。

## Implementation Steps

### Phase 0 · 离线判决实验（全部用 Python + 已有 bag/轨迹，不写 C++，不动 ROS）

**P0-A → P0-B 可并行；P0-C/P0-D 依赖 P0-A 的 Δt_camera；P0-E/P0-F 依赖 C/D。Phase 0 判决未通过前 P1 不启动。**

#### P0-A 时间戳与位姿插值核验（先做，成本最低、影响最大）
- 脚本 `experiments/octvox_ablation/18_timealign_probe.py`。
- 从 bag 读图像 `header.stamp`、LiDAR `header.stamp` 与 `end_time`、IMU；从 `base.txt` 取 LIO 位姿。
- 用 **IMU 角速度积分**（200 Hz）构造高频角运动参考曲线，与"由 LIO 位姿 slerp 插值出的角速度曲线"对比，**扫 Δt_camera ∈ [−0.15, +0.15] s** 求互相关峰。
  （v1 只用 10 Hz LIO 位姿做互相关 ⇒ 时间分辨率与运动激励不足，尤其转向平缓段；v2 必须叠加 IMU 通道。）
- 同时验证：以 LIO 帧尾戳为锚、改用插值而非固定偏移后，图像间相对旋转与 LIO 间相对旋转的残差是否下降。
- **产出**：Δt_camera 估计值与置信区间；`img_time_offset=0.1` 语义判定；确认"没有把真实运动错认为抖动"。

#### P0-B 纯平滑 Pareto 实验（评审重点保留项）
- 脚本 `experiments/octvox_ablation/17_smooth_ablation.py`，输入 `base.txt`。
- **三类严格分开，不得横比**：① 离线零相位（filtfilt / 中心窗口 SG）② 在线因果（EMA、前向差分正则）③ 允许固定延迟的滑窗平滑。
  ⚠️ SG 窗口 5/7/9 的中心形式在 10 Hz 下引入 ≈200/300/400 ms 延迟 ⇒ **不满足 100 ms 约束**，只能作为"延迟预算"的参照上限，不能作为在线候选。
- 扫参覆盖 `hf_θ P50 ∈ [0.05°, 0.51°]`。
- **每个点必须同时输出三类指标**（v2 关键补充：平滑轨迹与原轨迹的差异 ≠ 真实运动误差）：
  1. HF 抖动分位数（是否真被抑制）
  2. 相对原始 LIO 的偏移 P50/P95（修正量幅度）
  3. **真实运动误差**：快速转向段（角速度 >20°/s）的滞后误差 + 有 GT 数据（ntu_viral/eee_03、construction_seq2）上的 ATE 变化
- **判据**：纯平滑是图像方案必须超越的下限。若某在线因果点同时达成 `hf_θ P50 ≤0.15°` 且转向段滞后等效位移 ≤5 mm ⇒ 全案降级为"地图层接平滑位姿"，**不启动 P1**。

#### P0-C 视觉旋转可观测性实验（go/no-go 主体）
- 脚本 `experiments/octvox_ablation/19_visual_rot_obs.py`，抽 N=100–150 组相邻帧，分层覆盖：慢速直行、快速转向、低纹理天空段、有遮挡物段。
- 流程：降采样 0.5 → 金字塔 LK **双向跟踪**（前后向一致性剔除）→ 4×4 网格均匀化 → RANSAC 5-point；低基线段另跑 Homography 分解。
- 记录（不只内点率）：内点率、**特征空间覆盖率**、公共视场占比、旋转残差、以及**图像相对旋转序列自身的 3-tap hf_θ**（这就是新方案 hf_θ 的物理下限）。

#### P0-D 特征子集重复估计（量化真实测量方差，v2 新增）
- 同一对图像用不同子集重复求解：**100/200/300 点**；以及按 4×4 网格**分区单独估计**，比较分区结果离散度 ⇒ 分离"统计噪声"与"空间相关偏差"（动态物体、模糊、畸变残差产生的偏差不随 √N 收敛）。
- 与 IMU 预积分角速度、以及有 GT 片段做独立对照。
- **产出**：`σ_θ(N, 覆盖率)` 的经验曲线，作为 `Σ_vis,k` 动态建模依据；同时给出 0.0004° 理想下限与实际值的差距倍数。

#### P0-E 定标 + 指标自洽性映射（v2 新增，必须先于 P1）
- 用已有地图与探针，在 **2 m / 5 m / 10 m** 三档深度分别建立经验映射 `hf_θ → 地图法向厚度`。
  背景：按 `e ≈ d·tan(θ)`，5 m 处 0.51°→44.5 mm、0.30°→26.2 mm、0.20°→17.5 mm、0.10°→8.7 mm、**0.057°→5.0 mm**。
  ⇒ `hf_θ P50 ≤0.20°` 与 `地图厚度 ≤5 mm` 之间存在 **3.5× 量级差**，两套指标可能各自达标却做不出锐地图。必须用实测映射判断哪一个是真门槛，并据此**重新推导验收值**。
- 由 P0-C/D 的 σ_θ 与 P0-B 的 Pareto 前沿反解 `λ0 / λ2 / clip_rot / slew_rot`，不拍脑袋。

#### P0-F 已知扰动注入恢复实验（v2 新增，评审建议，说服力最强）
- 在 `base.txt`（或其平滑版本）上**人为注入已知旋转扰动**，检验修正器能否识别并抑制，同时保持低频真实运动：
  ① 0.05° 白噪声 ② 0.1° 逐帧随机 ③ 0.2° 交替（±符号）④ 低频真实旋转 + 高频噪声叠加。
- 指标：注入能量的抑制比（dB）、残余偏差、真实低频分量的相关性保持（与注入前轨迹的 DTW/相关系数）、以及"是否把真实运动也压掉了"。
- **优势**：误差真值已知，可直接算修正器的**恢复能力**，而不是只看地图变薄了多少（后者的因果链太长）。
- 该实验先用离线小求解器实现（NumPy 三对角 / Ceres-Python 或纯 scipy 高斯-牛顿均可，45 维量级），**不依赖 ROS 包**。

  - hf_θ >0.30° ⇒ 主路线判负，退化为"平滑 + 图像仅修低频漂移"。
- **P0-D**：若分区估计离散度显示存在不随 √N 收敛的空间相关偏差 ⇒ 视觉旋转不是独立测量，主路线降为"仅辅助低频"。
- **P3**：`b_refine` 地图不比 `b_lio` 锐 ⇒ 不开任何新默认，`pose_source` 保持 `lio`，结论写入 §36 并归档代码。

## Assumptions & Decisions

| # | 决定 | 依据 |
|---|---|---|
| 1 | **第一阶段只做旋转修正，平移沿用 LIO** | Essential Matrix 给不了平移模长独立观测；旋转是实测主收益通道（0.51°@5m ⇒ 44.5 mm）；投入产出比优于六自由度 |
| 2 | 0.0004° 只作理想同分布噪声下限，实际精度由 P0-C/D 实测 | 特征非独立、空间聚集、动态目标、模糊/畸变残差、5-point 低视差退化、LK 亚像素≠位姿亚像素 |
| 3 | 取消固定 −50 ms，改曝光中点 + LIO 轨迹插值 | 50 ms 在 20°/s 下即 1°，远超 0.2° 目标；扫描起点/终点/曝光中点是三个概念 |
| 4 | 绝对钳位 + 旋转/平移 slew + 运动学一致 + 渐进淡出 + 失败沿用，六层齐备 | 钳位只限幅度不保证帧间连续（+0.35°↔−0.35° 仍是 0.7° 跳变） |
| 5 | 旋转门控与平移门控分离，加入覆盖率/视场判据 | 原地缓转平移基线极小却最需修旋转 |
| 6 | 视觉残差用 `Log(R_visᵀ(R'ᵀ_{c,k}R'_{c,k+1}))` 完整形式，经 T_lc 转相机系 | 修正是世界系左乘，不能对 δ 做减法 |
| 7 | 先验合并为单一 `Σ_δ^{-1/2}δ` | v1 的 Λ0 与 Λa 语义重复，易重复计权 |
| 8 | λ2 约束修正量而非轨迹 | 避免为压抖动而压制真实运动 |
| 9 | `hf_θ→厚度` 映射须先实测再定验收值 | 0.20° 与 5 mm 之间存在 ~3.5× 量级差 |
| 10 | ATE 用配对 + 置信区间，不用 1 mm 硬数 | 轮次噪声可达 2.6× |
| 11 | 新建独立包，solution_b 估计器保留默认不用；引入 Ceres 2.0（不用 g2o） | 用户答复 + 环境实测 |
| 12 | 不做回环、不做样条主模型、不做直接法主通道 | 见"明确不做"三条实测/结构性理由 |
| 13 | 不假定 `img_time_offset=0.1` 正确；vlcal 不能替代 | vlcal 只标外参（已核实） |
| 14 | 官方 FAST-LIVO2 输出不能当真值 | §0 约定：两轮自差异 P50 73.9 mm |
