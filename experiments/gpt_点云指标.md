这次结果比最初预想的要有价值，尤其是冗余聚类分析。我认为你们已经从「寻找一个能区分两组点云的指标」，推进到了「识别点云质量的独立退化维度」。

我基本认可最终的四指标方案，但有几个地方值得进一步审查，特别是局部点间距、ROR 和栅格域椒盐率之间的关系。

## 1. 我对这次结果的判断

总体结论：方向正确

### 第一，12 个指标归入局部点间距族，是一个重要发现

你们发现：

- NN Distance；
- KNN 邻域半径；
- PCA Roughness；
- Local Residual；
- Isolated Ratio；
- Cloud-to-Cloud Distance；

在当前实验中高度相关。

这说明这些指标虽然使用不同的数学表达式，但最终可能都在反映同一个底层现象：

点云局部空间采样尺度增大，或者点的空间分布发生弥散。

这也修正了我之前推荐的指标组合。

之前我把 PCA Roughness、NN Distance CV、Plane P95、Surface Variation 当成不同维度推荐，现在看来，在你们这个具体场景下，这种分类过于乐观。

不过要保留一个限定：这是当前招牌数据、当前 ROI 和当前采样条件下的经验冗余，不代表这些指标在所有点云场景中都等价。

### 第二，G15 Roughness CV 是一个值得保留的独立维度

我认为它甚至可能比绝对粗糙度更有研究价值。

普通粗糙度回答：

> 点云平均有多粗糙？

Roughness CV 回答：

> 点云的粗糙程度在空间上是否均匀？

例如：

- A：所有区域的粗糙度都在相对稳定的范围内。
- B：一部分区域非常干净，另一部分区域严重散乱。

即使两者平均粗糙度接近，CV 也可能明显不同。

这对于 MID360 在不同反射率、不同入射角、局部遮挡环境下的表现尤其有价值。

建议保留 G15，但进一步检查它是否会被局部点密度差异影响。

### 第三，点域 RGB 指标失效，栅格域指标有效

这个结论非常值得记录。

你们实际上发现了一个数据表达层面的差异：

- 点域：每个表面的 RGB 可能都很稳定。
- 投影域：不同深度表面的点可能落到相同像素，造成颜色混叠。

因此，点域颜色方差并不能反映最终可视化图像的质量。

这也意味着，RGB 质量应该被定义为投影表达质量，而不只是点本身的颜色质量。

但这里有一个需要进一步确认的问题：栅格域椒盐增加，究竟是 RGB 噪声，还是不同深度表面的投影碰撞？

如果是后者，它反映的是几何投影与遮挡关系，而不完全是颜色噪声。

## 2. 我认为目前四指标体系还需要注意两个问题

### 问题 A：G00 和 O02 可能并非完全独立

当前四个指标：

| 指标                    | 对应维度          |
| --------------------- | ------------- |
| G00 Nb Radius\@K10    | 局部点间距         |
| G15 Roughness CV\@K25 | 粗糙度空间不均匀性     |
| O02 ROR Ratio\@3cm    | 固定物理阈值下的稀疏点比例 |
| Raster Salt-Pepper    | 投影域颜色污染       |

其中 G00 和 O02 之间可能仍存在较强的关系。

因为 ROR 的核心逻辑是：

一个点在 3 cm 半径内找不到足够数量的邻居，就判为异常点。

而 G00 反映的是找到 K 个邻居需要多大的空间半径。

两者虽然不是同一个统计量，但都受到局部采样间距影响。

建议追加一次分析：

- G00 与 O02 的 Spearman 相关性；
- G00 与 O02 在不同 ROI 中的相关性；
- 不同点密度条件下 O02 是否仍然能够提供额外区分信息。

如果相关性很高，O02 可能只是局部点间距的阈值化表达，而不是完全独立的噪声维度。

但我仍然倾向于暂时保留它，因为它具有明确的工程意义：能够反映固定物理尺度下的局部点云稀疏程度。

### 问题 B：点数差异的解释需要稍微严谨一些

你们计算：

- SL 少 13% 点；
- 理论间距增加约 7.4%；
- 实际间距增加 19.5%。

这个分析方向是正确的。

但建议报告中把它表述为：

采样数量变化的理论影响

假设二维表面上的采样均匀，点间距近似满足：

\\[ d\propto N^{-1/2} \\]

点数减少13%：

\\[ \frac{d_B}{d_A}=\frac{1}{\sqrt{0.87}} \approx1.072 \\]

实测结果

\\[ \frac{d_B}{d_A}=1.195 \\]

# +11.5%

相对于理论采样间距预测值的额外增幅，约为 11.5%（使用未四舍五入的原始数据计算）。

你们所说的 2.6 倍，实际上是：

\\[ \frac{19.5\\%}{7.4\\%}\approx2.64 \\]

它表示实际增幅约为理论采样数量效应的 2.6 倍，而不是说 2.6 倍的点间距完全由噪声造成。

另外，这个推导假设采样均匀、二维表面、相同面积。MID360 的扫描角度分布、入射角、遮挡和回波选择都可能影响点间距，因此最好称为理论基线，而不是精确的噪声分解。

## 3. 我建议追加的四项实验

我不建议再大规模增加指标。55 个指标已经足够丰富，下一阶段应该针对四个核心维度做深入验证。

| 实验            | 目的                | 优先级 |
| ------------- | ----------------- | --- |
| G00-O02 条件相关性 | 判断两个指标是否真正独立      | 高   |
| G15 密度敏感性     | 排除点数变化造成的假性粗糙度不均匀 | 高   |
| Raster 深度分层   | 排除两张表面投影重叠造成的假椒盐  | 高   |
| 重复扫描稳定性       | 判断结论能否跨扫描复现       | 高   |

### 实验 1：G00 与 O02 的条件相关性

不仅计算普通 Spearman，还建议按局部密度分层。

例如，把 ROI 分为高密度、中密度、低密度三个区域，分别计算 O02。

如果在相同局部密度下，SL 仍然具有明显更高的 ROR，说明它确实检测到了额外的空间异常。

### 实验 2：G15 的密度敏感性

建议进行随机下采样实验。

将官方点云随机下采样至：

- 95%；
- 90%；
- 87%；
- 80%；
- 70%。

每种比例重复 20 次。

然后重新计算 G15。

理想情况

如果下采样至 87% 后，G15 仍基本稳定，而原始 A/B 差异明显，那么它更有资格成为独立的质量指标。

### 实验 3：栅格域 RGB 深度分层

这是我最希望你们做的一个实验。

建议同一张投影图分别输出：

1. 普通 RGB 栅格。
2. Z-buffer 最近表面 RGB 栅格。
3. 按深度区间分层的 RGB 栅格。
4. 同一深度层内的 RGB 椒盐率。

这样可以回答：

- 是否因为两张表面重叠而产生椒盐？
- 是否因为几何位置散乱而导致像素混叠？
- 同一个表面内部是否真的出现 RGB 颜色污染？

如果深度分层之后，SL 的椒盐率仍然明显更高，那么这个指标的价值就更明确了。

### 实验 4：跨扫描复现

建议不同模式分别采集至少 5～10 组数据。

对最终四个指标分别统计：

- 配对均值差；
- 配对标准差；
- Cohen's \\(d_z\\)；
- Bootstrap 95% 置信区间；
- 每次扫描的优劣方向。

尤其关注 G15 和栅格域椒盐率。

## 4. 最终我建议采用的指标体系

目前可以先定为四个一级指标，但保留一个备用指标。

## MID360 点云质量评价 V1.0

当前实验推荐架构，尚待跨场景验证

Q1 局部空间离散度

核心

`G00_Nb_Radius@K10`

反映局部点间距与空间弥散程度。

Q2 粗糙度空间不均匀性

核心

`G15_Roughness_CV@K25`

反映不同局部区域的质量一致性。

Q3 固定尺度异常点比例

核心

`O02_ROR_Ratio_3cm`

反映指定物理邻域内的局部稀疏与孤立现象。

Q4 投影颜色污染

核心

`Raster Salt-Pepper Ratio`

反映最终二维投影的颜色污染程度，需明确遮挡和深度碰撞的处理规则。

备用：局部间距 P95

诊断指标

`D05_NN_P95`

用于观察局部最差区域，不纳入综合评分，避免与 Q1 重复计权。

## 5. 可以考虑进一步形成一个更有价值的工程结论

我认为这次实验最重要的发现，不只是 SL 的点云质量比官方输出差，而是已经初步识别出了不同的质量退化机制：

| 退化机制    | 对应指标   | 工程意义         |
| ------- | ------ | ------------ |
| 空间弥散    | G00    | 点的位置不够集中     |
| 局部质量不均匀 | G15    | 某些区域明显比其他区域差 |
| 固定尺度孤立点 | O02    | 存在局部缺少有效邻居的点 |
| 投影颜色污染  | Raster | 最终呈现的图像质量下降  |

这比单纯报告 RMSE 或点数更有价值。

特别是你们之前研究过 MID360 在煤粉环境中的回波质量、Sensitive 模式以及 Super-LIO 点云表现，这套体系后续可以用来比较不同传感器配置和处理策略。

我建议下一阶段暂时停止扩展候选指标，把精力放在四个核心指标的独立性、密度鲁棒性和跨扫描复现上。 只有通过这三项验证，才值得把它们正式固化为你们的点云质量评价标准。
